# Раздел 5. Статистический анализ данных. Описательная статистика

> Лекция 5. Описание распределений и основы теории вероятностей.

## Цель занятия

Освоить меры центра и разброса, понятия распределения, нормального и
биномиального распределений.

## 1. Типы переменных

- **Непрерывные** — принимают любое значение из диапазона (рост, вес, цена);
- **Дискретные** — принимают отдельные значения (число пассажиров, возраст в
  годах).

## 2. Меры центральной тенденции

| Мера | Формула | Свойство |
|------|---------|----------|
| среднее | $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$ | чувствительно к выбросам |
| медиана | $x_{(n/2)}$ | устойчива к выбросам |
| мода | наиболее частое значение | для категориальных |

## 3. Меры разброса

- **Дисперсия** $\sigma^2 = \frac{1}{n}\sum (x_i - \bar{x})^2$;
- **Стандартное отклонение** $\sigma = \sqrt{\sigma^2}$ (в единицах данных);
- **размах** = $\max - \min$;
- **IQR** = $Q_3 - Q_1$ (межквартильный размах).

```python
df["age"].mean()      # среднее
df["age"].std()       # стандартное отклонение
df["age"].var()       # дисперсия
```

## 4. Гистограммы частот и плотностей

- **гистограмма частот** — число наблюдений в каждом интервале;
- **гистограмма плотностей** — нормирована так, что площадь равна 1.

```python
df["age"].plot(kind="hist", bins=30, density=False)   # частоты
df["age"].plot(kind="hist", bins=30, density=True)    # плотность
df["age"].plot(kind="kde")                            # оценка плотности
```

## 5. Скошенность (skewness)

Коэффициент асимметрии:

$$\gamma_1 = \frac{1}{n}\sum_{i=1}^{n}\left(\frac{x_i - \bar{x}}{\sigma}\right)^3$$

- $\gamma_1 > 0$ — правый «хвост» (скошено вправо);
- $\gamma_1 < 0$ — левый хвост;
- $\gamma_1 \approx 0$ — симметрично.

```python
df["age"].skew()
```

## 6. Теория вероятностей

- **События** пересекающиеся (есть общие исходы), **взаимоисключающие**
  ($P(A \cap B) = 0$), **независимые** ($P(A \cap B) = P(A)P(B)$).
- **Умножение вероятностей**: для независимых событий
  $P(A \text{ и } B) = P(A)\cdot P(B)$.
- **Сложение**: $P(A \text{ или } B) = P(A) + P(B) - P(A \cap B)$.

## 7. Случайные величины и распределения

**Случайная величина** — функция, сопоставляющая исходу число. Распределение
задаётся функцией плотности $f(x)$ (непрерывный случай) или вероятностями
$P(X = k)$ (дискретный случай).

### Нормальное распределение

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

- **математическое ожидание** $\mu$ — центр распределения;
- **дисперсия** $\sigma^2$ — разброс;
- правило «трёх сигм»: $\approx 68\%$, $95\%$, $99.7\%$ значений лежат в
  пределах $\mu \pm \sigma$, $\mu \pm 2\sigma$, $\mu \pm 3\sigma$.

```python
import numpy as np
np.random.normal(loc=0, scale=1, size=1000)   # нормальная выборка
```

### Биномиальное распределение

Число успехов в $n$ независимых испытаниях с вероятностью успеха $p$:

$$P(X = k) = C_n^k\, p^k (1-p)^{n-k}$$

- мат. ожидание $\mu = np$;
- дисперсия $\sigma^2 = np(1-p)$.

### Аппроксимация биномиального нормальным

При большом $n$ биномиальное распределение приближается нормальным с теми же
$\mu$ и $\sigma$ (теорема Муавра–Лапласа, частный случай ЦПТ).

```python
np.random.binomial(n=100, p=0.5, size=1000)
```

## Резюме

- Среднее/медиана/мода — центр; дисперсия/σ/IQR — разброс; skew — асимметрия.
- Нормальное распределение задаётся $(\mu, \sigma)$; биномиальное — $(n, p)$
  и при больших $n$ сходится к нормальному.
