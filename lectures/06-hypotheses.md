# Раздел 6. Статистический анализ данных. Статистические гипотезы

> Лекция 6. Проверка гипотез, t-тест, A/B тесты, bootstrap.

## Цель занятия

Научиться формулировать и проверять статистические гипотезы в Python.

## 1. Выборки

- **Случайная выборка** — каждый объект отбирается с равной вероятностью;
- **стратифицированная** — генеральная совокупность делится на страты
  (группы), из каждой отбирается случайная подвыборка (сохраняет пропорции).

```python
df.sample(n=100, random_state=42)                      # случайная выборка
df.groupby("group", group_keys=False).sample(frac=0.1) # стратифицированная
```

## 2. Оценка параметров генеральной совокупности

По выборке оценивают параметры (среднее, долю). Оценки бывают:

- **точечные** — одно число (выборочное среднее $\bar{x}$);
- **интервальные** — доверительный интервал.

**Выборочное распределение** — распределение статистики (например, среднего)
по всем возможным выборкам. Стандартная ошибка среднего:

$$SE = \frac{\sigma}{\sqrt{n}}$$

## 3. Центральная предельная теорема (ЦПТ)

При достаточно большом объёме выборки $n$ распределение выборочного среднего
приближается к нормальному с параметрами $(\mu,\ \sigma/\sqrt{n})$, **независимо**
от распределения исходной величины.

## 4. Формулирование гипотез

- **Нулевая гипотеза** $H_0$ — «эффекта нет» (например, $\mu = \mu_0$);
- **альтернативная** $H_1$ — «эффект есть».

| Тип | $H_0$ | $H_1$ |
|-----|-------|-------|
| двусторонняя | $\mu = \mu_0$ | $\mu \ne \mu_0$ |
| односторонняя (вправо) | $\mu \le \mu_0$ | $\mu > \mu_0$ |
| односторонняя (влево) | $\mu \ge \mu_0$ | $\mu < \mu_0$ |

**p-value** — вероятность получить наблюдаемое (или более экстремальное)
значение при условии, что $H_0$ верна.

- $p < \alpha$ (обычно $\alpha = 0.05$) → $H_0$ отвергается;
- $p \ge \alpha$ → данных для отклонения $H_0$ недостаточно.

## 5. t-тест в Python

### Одновыборочный t-тест (проверка $\mu = \mu_0$)

```python
from scipy import stats

stats.ttest_1samp(df["age"], popmean=30)   # двусторонний
```

### Гипотеза о равенстве средних двух совокупностей

```python
# независимые выборки (t-тест Стьюдента)
stats.ttest_ind(group_a, group_b)

# зависимые (парные) выборки
stats.ttest_rel(before, after)
```

### Односторонние гипотезы

`scipy` возвращает двусторонний p-value. Для односторонней гипотезы его
делят пополам и проверяют направление по знаку t-статистики.

```python
res = stats.ttest_ind(a, b)
p_one_sided = res.pvalue / 2 if res.statistic > 0 else 1 - res.pvalue / 2
```

## 6. A/B тесты

A/B тест — сравнение двух вариантов (контроль/тест) по целевому показателю:

1. сформулировать $H_0$ (показатели равны) и $H_1$;
2. выбрать метрику и уровень значимости $\alpha$;
3. собрать данные (случайное разделение на группы);
4. применить подходящий тест (t-тест, $\chi^2$ для долей);
5. принять решение по p-value.

## 7. Bootstrap

Bootstrap — метод оценки распределения статистики путём многократной
повторной выборки **с возвращением**:

```python
import numpy as np

def bootstrap_mean(data, n_iter=1000):
    means = np.empty(n_iter)
    for i in range(n_iter):
        sample = np.random.choice(data, size=len(data), replace=True)
        means[i] = sample.mean()
    return means

means = bootstrap_mean(group_a)
np.percentile(means, [2.5, 97.5])   # 95% доверительный интервал
```

## Резюме

- Гипотезы: $H_0$ (нет эффекта) против $H_1$; решение по p-value и $\alpha$.
- t-тест: `ttest_1samp`, `ttest_ind` (независимые), `ttest_rel` (парные).
- ЦПТ обосновывает нормальность выборочного среднего; bootstrap оценивает
  распределение статистики без параметрических предположений.
