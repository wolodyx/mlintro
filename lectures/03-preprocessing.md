# Раздел 3. Предобработка данных. Визуализация данных

> Лекция 3. Подготовка данных к анализу и машинному обучению.

## Цель занятия

Научиться находить и обрабатывать пропуски, приводить типы, удалять
дубликаты — готовить «сырые» данные к анализу.

## 1. Пропуски данных (missing values)

Типы пропусков (по механизму возникновения, классификация Д. Рубина):

| Тип | Аббревиатура | Смысл |
|-----|--------------|-------|
| Полностью случайные | MCAR | пропуск не зависит ни от данных, ни от пропуска |
| Случайные | MAR | пропуск зависит от наблюдаемых данных |
| Неслучайные | MNAR | пропуск зависит от самого пропущенного значения |

В `pandas` пропуски представляются как `NaN` (числовые) и `None` (объектные).

## 2. Работа с пропусками

```python
import pandas as pd

# обнаружение
df.isna()            # маска пропусков
df.isna().sum()      # количество пропусков по колонкам
df.notna()           # обратная маска

# удаление
df.dropna()                     # удалить строки с любым пропуском
df.dropna(subset=["age"])       # только по колонке
df.dropna(axis=1)               # удалить колонки

# заполнение
df.fillna(0)                    # константой
df.fillna({"age": 0, "name": "—"})   # по колонкам
df["age"].fillna(df["age"].median()) # медианой
```

## 3. Пропуски в количественных переменных

Заполняют центральной характеристикой распределения:

- **медиана** — устойчива к выбросам, предпочтительна при скошенности;
- **среднее** — для симметричных распределений;
- **min / max** — как крайние варианты (используются реже).

```python
df["age"] = df["age"].fillna(df["age"].median())
df["income"] = df["income"].fillna(df["income"].max())
```

## 4. Пропуски в категориальных переменных

- замена значением по умолчанию / заглушкой: `"не указано"`, `"другое"`;
- замена **модой** (наиболее частым значением);
- удаление строк с пропуском.

```python
df["city"] = df["city"].fillna("не указано")
df["embarked"] = df["embarked"].fillna(df["embarked"].mode()[0])
```

## 5. Изменение типов данных

```python
df["age"] = pd.to_numeric(df["age"], errors="coerce")  # в число, ошибки -> NaN
df["id"]  = df["id"].astype(int)                        # явное приведение
df["category"] = df["category"].astype("category")       # категориальный тип
```

`errors="coerce"` превращает нечисловые значения в `NaN` — удобно для
обнаружения «грязных» данных.

## 6. Дубликаты

```python
# явные дубликаты
df.duplicated()                    # маска дубликатов
df.drop_duplicates()               # удалить полностью совпадающие строки
df.drop_duplicates(subset=["id"])  # по конкретным колонкам
df.reset_index(drop=True)          # сброс индекса после удаления

# неявные дубликаты (разный регистр/пробелы)
df["name"] = df["name"].str.lower().str.strip()
df.drop_duplicates(subset=["name"])
```

## 7. Визуализация: первые шаги

```python
import matplotlib.pyplot as plt
import seaborn as sns

df["age"].hist(bins=20)                  # гистограмма
df["age"].plot(kind="box")               # ящик с усами
df.plot.scatter(x="age", y="fare")       # точечный график
sns.countplot(data=df, x="sex")          # счётчики категорий
sns.heatmap(df.isna(), cbar=False)       # тепловая карта пропусков
plt.show()
```

## Резюме

- Пропуски: обнаруживать `isna()`, заполнять `fillna()` или удалять `dropna()`.
- Числовые — медианой/средним, категориальные — заглушкой/модой.
- Типы — `to_numeric(errors="coerce")`, `astype`.
- Дубликаты — `drop_duplicates`, неявные — нормализация регистра/пробелов.
