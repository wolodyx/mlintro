## Ставим задачу

В этом разделе мы пройдем через последовательность шагов, в результате которых обучим модель машинного обучения, классифицирующая ирисы по сортам.
В качестве исходных данных нам доступна таблица измерений 150 цветков.
У каждого цветка измерили длину и ширину лепестков, а также длину и ширину чашелистиков.

Опытный эксперт уже соотнес все цветки одному из трех сортов:

Наша задача состоит в построении модели машинного обучения по этим данным, которая сможет предсказать сорт для неизвестного цветка ириса по четырем измерениям.

Данная задача относится к **задаче классификации**.
В ней следует определить принадлежность объекта (цветка) к одному из известных **классов** (сортов).
Так как классы известны на момент обучения, то наша задача, как и любая задача классификации относится к **задаче обучения с учителем**.
Каждый из сортов ириса образует класс.
В наборе данных три класса, поэтому это задача **трехклассовой классификации**.
Четыре параметра 150 цветков образуют таблицу (двумерный массив) из 150 строк и 4 столбцов.
Строка в таблице характеризует один измеренный объект (цветок) и называется **образцом**.
Столбец в таблице определяет **признак** объекта.
Каждый объект содержит 4 числовых признака: длину и ширину лепестка, длину и ширину чашелистика.
Каждому цветку сопоставлен его сорт через **метку**.
Такое сопоставление представлено массивом-столбцом с целыми числами.
Число в массиве (метка) указывает на класс.

## Разделяем данные

После обучения нам придется проверить, насколько модель работает правильно, т.е. оценить ее **предсказательную способность**.
Для этого мы воспользуемся образцами из имеющегося набора данных.
Но нам следует скрыть эти данные от модели, чтобы она не запомнила их и не взяла готовый ответ.
Такая ситуация называется **утечкой данных**, а если быть конкретнее, то **утечкой целевой переменной**.

Чтобы предотвратить утечку данных, мы разделим исходный набор данных на **обучающий и контрольный наборы**.
На обучающем наборе данных модель будет обучена, а на контрольном проверена.
В библиотеке `scikit-learn` есть функция [`sklearn.model_selection.train_test_split`](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.train_test_split.html).
Она перемешивает и разбивает набор данных на две части в заданном соотношении.

По умолчанию функция отбирает в обучающий набор 75% образцов вместе с метками, а оставшиеся 25% образцов объявляются контрольным набором. 
Перемешивание данных управляется параметром `shuffle`, которое по умолчанию включено.
В нашем случае перемешивание данных обязательно, потому что образцы отсортированы по целевой переменной. 

``` python
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    iris_dataset['data'],
    iris_dataset['target'],
    random_state=0)
```

Функция принимает один или более массивов и каждую разбивает на две части в заданном соотношении.
В примере выше мы передали массивы `data` и `target`, а результаты разбиения вернулись в виде переменных `X_train`, `X_test`, `y_train`, `y_test`.
Образцы из `X_train` и `X_test` дают в сумме массив `data`, а `y_train`, `y_test` -- `target`.

Функция `train_test_split` при перемешивании образцов использует генератор псевдослучайных чисел.
Каждый ее запуск выдаст другую перестановку, которая незначительно, но повлияет на обучение.
Повторно воспроизвести полученный результат мы сможем, только если зафиксируем инициализирующее значение генератора параметром `random_state`.

```{note}
Следует всегда задавать `random_state` при использовании рандомизированных процедур.
```


## Обучаем модель

В этой части мы создадим и обучим нашу модель.

Библиотека `scikit-learn` включает в свой состав много алгоритмов классификации, которые могут быть использованы для построения моделей.
Все эти алгоритмы оформлены в виде классов, отнаследованных от базового `Estimator`.
Объекты этих классов также будут представлять модели машинного обучения.
Перечислим некоторые алгоритмы классификации из `scikit-learn`:
* [sklearn.neighbors.KNeighborsClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.KNeighborsClassifier.html), алгоритм k ближайших соседей;
* [sklearn.tree.DecisionTreeClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.tree.DecisionTreeClassifier.html), деревья решений;
* [sklearn.linear_model.LogisticRegression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html), логистическая регрессия;
* [sklearn.ensemble.RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html), случайный лес.

В этом разделе мы воспользуемся классификатором на основе **алгоритма k ближайших соседей**.
Построение этой модели заключается лишь в запоминании обучающего набора.
Для того, чтобы сделать прогноз для новой точки данных, алгоритм находит точку в обучающем наборе, которая находится ближе всего к новой точке.
Затем он присваивает метку, принадлежащую этой точке обучающего набора, новой точке данных.

k в методе k ближайших соседей означает, что вместо того, чтобы использовать лишь ближайшего соседа новой точки данных, мы в ходе обучения можем рассмотреть любое фиксированное число (k) соседей (например, рассмотреть ближайшие три или пять соседей).
Тогда мы можем сделать прогноз для точки данных, используя класс, которому принадлежит большинство ее соседей.

Алгоритм классификации на основе метода k ближайших соседей реализован в классификаторе `KNeighborsClassifier` модуля `neighbors`.
Прежде чем использовать эту модель, нам нужно создать объект-экземпляр класса.
Это произойдет, когда мы зададим параметры модели.
Самым важным параметром `KNeighborsClassifier` является количество соседей, которые мы установим равным 1.

``` python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=1)
```

Объект `knn` включает в себя алгоритм, который будет использоваться для построения модели на обучающих данных, а также алгоритм, который сгенерирует прогнозы для новых точек данных.
Он также будет содержать информацию, которую алгоритм извлек из обучающих данных.

Для построения модели на обучающем наборе, мы вызываем метод `fit` объекта `knn`, который принимает в качестве аргументов массив `NumPy` `X_train`, содержащий обучающие данные, и массив `NumPy` `y_train`, соответствующий обучающим меткам.
Метод `fit` возвращает сам объект `knn` (и изменяет его), таким образом, мы получаем строковое представление нашего классификатора.
Оно показывает нам, какие параметры были использованы при создании модели.

``` python
knn.fit(X_train, y_train)
```

## Получаем прогнозы

Теперь мы можем получить прогнозы, применив эту модель к новым данным, по которым мы еще не знаем правильные метки.
Представьте, что мы нашли в дикой природе ирис с длиной чашелистика 5 см, шириной чашелистика 2.9 см, длиной лепестка 1 см и шириной лепестка 0.2 см.
К какому сорту ириса нужно отнести этот цветок?
Мы можем поместить эти данные в массив `NumPy`.

Обратите внимание, что мы записали измерения по одному цветку в двумерный массив NumPy, поскольку `scikit-learn` работает с двумерными массивами данных.
Чтобы сделать прогноз, мы вызываем метод `predict` объекта `knn`.

``` python
import numpy as np
X_new = np.array([[5, 2.9, 1, 0.2]])
prediction = knn.predict(X_new)
print("Прогноз:")
print(prediction)
print("Спрогнозированная метка:");
print(iris_dataset['target_names'][prediction]);
```

Наша модель предсказывает, что этот новый цветок ириса принадлежит к классу 0, что означает сорт setosa.
Но как узнать, можем ли мы доверять нашей модели?
Правильный сорт ириса для этого примера нам неизвестен, а ведь именно получение правильных прогнозов и является главной задачей построения модели!

## Оцениваем качество

Это тот самый момент, когда нам понадобится созданный ранее тестовый набор.
Эти данные не использовались для построения модели, но мы знаем правильные сорта для каждого ириса в тестовом наборе.
Таким образом, мы можем сделать прогноз для каждого ириса в тестовом наборе и сравнить его с фактической меткой (уже известным сортом).
Мы можем оценить качество модели, вычислив **долю правильных ответов** (accuracy) -- процент цветов, для которых модель правильно спрогнозировала сорта

``` python
y_pred = knn.predict(X_test)
print("Прогнозы для тестового набора:")
print(y_pred)
print("Правильность на тестовом наборе:")
print(np.mean(y_pred == y_test))
```

Кроме того, мы можем использовать метод `score` объекта `knn`, который вычисляет правильность модели для тестового набора.

``` python
print("Правильность на тестовом наборе:")
print(knn.score(X_test, y_test))
```

Правильность этой модели для тестового набора составляет около 0.97, что означает, что мы дали правильный прогноз для 97% ирисов в тестовом наборе.
При некоторых математических допущениях, это означает, что мы можем ожидать, что наша модель в 97% случаев даст правильный прогноз для новых ирисов.
Для нашего ботаника-любителя этот высокий уровень правильности означает, что наша модель может быть достаточно надежной в использовании.

## Выводы

Набор данных `Iris` состоит из двух массивов `NumPy`: один содержит данные и в `scikit-learn` обозначается как `X`, другой содержит правильные или нужные ответы и обозначается как `y`.
Массив `Х` представляет собой двумерный массив признаков, в котором одна строка соответствует одной точке данных, а один столбец – одному признаку.
Массив `у` представляет собой одномерный массив, который для каждого примера содержит метку класса, целое число от 0 до 2.

Мы разделили наш набор данных на *обучающий набор*, чтобы построить нашу модель, а также *тестовый набор*, чтобы оценить, насколько хорошо наша модель будет классифицировать новые, ранее незнакомые ей данные.

Мы выбрали **алгоритм классификации k ближайших соседей**, который генерирует прогноз для новой точки данных, рассматривая ее ближайшего соседа(ей) в обучающем наборе.
