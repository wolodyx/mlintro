# 🛠️ Настройка рабочей среды

## Подготовка виртуальной машины с Ubuntu

Локальный запуск `Jupyter Notebook`:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```
