# Основы NumPy

<!-- Краткое описание NumPy -->
NumPy -- это популярная библиотека Python с открытым исходным кодом для научных вычислений.
В ее основе лежит класс многомерного массива с однородными данными и множество операций вокруг него.

Массивы NumPy как строительные блоки используются во многих популярных библиотеках машинного обучения.
На них основаны или их принимают как входные данные такие библиотеки как Pandas, Scikit-learn, SciPy, Matplotlib, Seaborn, TensorFlow, PyTorch, Keras.
Именно поэтому важно понимать основы и уметь пользоваться NumPy.
Понимание принципов, заложенных в NumPy, не пропадут зря, и помогут при освоении Pandas.

## Эффективность операций NumPy

Сравним скорость выполнения операций над одним миллионом целых чисел в классическом списке Python и одномерном массиве NumPy следующей программой.
Выберем операцию вида `x * 2 + 1`, а для измерения времени воспользуемся магической командой `%timeit`.

```` {note}
Общепринято импортировать модуль NumPy с псевдонимом:
``` python
import numpy as np
```
````

```{code-cell} python
import numpy as np

N = 1_000_000

py_list = list(range(N))
np_array = np.arange(N)

print(f"Сравнение на {N:,} элементах\n")

print("Python list:  [x * 2 + 1 for x in lst]")
%timeit [x * 2 + 1 for x in py_list]

print("\nNumPy array:  arr * 2 + 1")
%timeit np_array * 2 + 1
```

Запуск программы дал следующий вывод.
По нему мы можем судить, что скорость операции NumPy относительно Python-инструкции выше в 64 раза.

```
Сравнение на 1,000,000 элементах

Python list:  [x * 2 + 1 for x in lst]
51.2 ms ± 178 μs per loop (mean ± std. dev. of 7 runs, 10 loops each)

NumPy array:  arr * 2 + 1
803 μs ± 15.1 μs per loop (mean ± std. dev. of 7 runs, 1,000 loops each)
```

Такая значительная разница в скорости стало возможным за счет того, что NumPy известен тип данных элементов и значения в памяти расположены рядом.
Это позволяет применить операцию ко всем данным сразу.
Такие операции называются **векторизированными**.
Конечно, циклы и индексации никуда не делись, они скрыты на уровне реализации библиотеки на языке программирования Си.
Но с точки зрения интерпретатора Python, все элементы массива модифицируются за одну операцию.

Векторизация, скрывая циклы, делает код более читаемым.
Обратите внимание на лаконичность записи выражения операции в векторизированной форме:
```
np_array * 2 + 1
```
Здесь сложнее допустить ошибку, чем если бы применяли операцию к каждому элементу массива.

``` {note}
NumPy предлагает быстрые операции, лаконичные и выразительные формы их записи.
```


## Многомерные массивы

Современные компьютеры оперируют с числами.
В таких областях как численное моделирование и машинное обучение оперируют огромным количеством чисел.
Самый эффективный способ организовать числа для быстрого доступа к ним -- поместить их в массивы.
Разделить числа на группы для их структурирования можно добавив в массив дополнительные измерения.
Двумерные, трехмерные и многомерные массивы являются обычным делом в сложных и объемных вычислениях.
Массивы характеризуются следующими свойствами:
* элементы массива располагаются плотно и фиксированным шагом;
* размер массива заранее известен и неизменяем (изменяемы только содержимое элементов);

Наиболее часто используются одномерные и двумерные массивы.

Каждое из измерений несет смысл.

Рассмотрим примеры, где моделируемые объекты раскладываются на массивы чисел.

<!-- Численное моделирование на структурированной сетке -->

### Набор изображений в формате RGB
Изображения представляются двумерным массивом пикселей.
Каждый пиксель в формате RGB кодируется тремя цветовыми компонентами, обозначаемых через `R` (red, красный), `G` (gree, зеленый) и `B` (blue, синий).
Цветной пиксель вводит дополнительное измерение размером в три в исходный двумерный массив и в итоге группирует набор чисел в трехмерный массив.
``` {figure} ./excalidraw/image-with-rgb.excalidraw.png
```

<!-- Обучение нейросети на изображениях -->
Для обучения нейросети используют *обучающий набор данных*, в нашем случае изображений.
Обучение происходит итерационно, не на всех данных сразу, а на порциях изображений.
Исходный набор данных разбивается на такие порции, называемых *батчами*.
Такая организация вводит в представление выше дополнительные, четвертое и пятое измерения.
В пятом измерении весь датасет разбивается на порции, в четвертом измерении представлены изображения в порции.
``` {figure} ./excalidraw/dataset-batch-img.excalidraw.png
```

Таким образом массив индексация `dataset[i,j,k,l,m]` обращается в наборе данных к `i`-тому батчу, `j`-тому изображению, пикселю в строке `k` и столбце `l` и цветовому каналу под номером `m`.

### Структурированная расчетная сетка

Некоторые численные расчеты в объеме проводят в кубической области, разбитой структурированно на шестигранные ячейки.
В таком разбиении появляется расчетная область, состоящая из узлов, размещенных по трем направлениям, которые обозначают как `I`, `J`, `K`.
Каждый узел в свою очередь представлен точкой из трех координат `x`, `y` и `z`.
В результате мы получаем 4-мерный массив: трехмерный кубический массив, элементами которого являются три числа `(x,y,z)` - еще одно измерение размером 3.
Такой 4-мерный массив описывает геометрию и разбиение расчетной области на ячейки.
Для результатов расчета необходимо будет сохранить вычисленные неизвестные с привязкой к узлам, например: скорости по трем направлениям, давление и температура.
Они встанут на места координат узлов.
Но для нестационарных расчетов, где неизвестные будут меняться, появится дополнительное размерность в виде времени.
В итоге получится 5-мерный массив: по выражению `result[time,i,j,k,y]` мы обращаемся в моменте времени `time` узла индексом `(i,j,k)` и вычисленной величине `y`.



## Связь представления индекса с массивом

<!-- Визуализация многомерности -->
Рассмотрим два приема, позволяющие мысленно изобразить многомерные массивы.
Рассмотрим элеменент массива как прямоугольный контейнер, содержащий некоторое значение, например, число.
Одномерный массив представляет объединение прямоугольников в строку.
Двумерный массив есть одномерный массив одномерных массивов: каждая ячейка такого массива содержит уже не число, а массив строку.
Рекурсивно применяя этот прием для, получаем, что `N`-мерный массив есть массив `(N-1)`-мерного массива.
``` {figure} ./excalidraw/nd-array.excalidraw.png
```

Во втором способе мы используем возможности трехмерного пространства, чтобы нарисовать двумерный массив как таблицу, а трехмерный -- как блок (прямоугольный параллелепипед).
При переходе на четвертое измерение мы снова изображаем массив как строку со вложенными блоками.
В общем случае получается, что N-мерный массив изображается как:
* строка, если N при делении нацело дает в остатке 1;
* таблицу, если дает в остатке 2;
* блок, если N делится нацело.

Содержимое массива будет числом, если `N < 4`, иначе блоком.

<!-- Массивы в памяти -->
Память компьютера представляет последовательность ячеек.
Каким образом многомерная структура данных раскладывается на нее?
Количество измерений массива называется **размерностью**.
Количество ячеек по каждому измерению определяет **форму массива**.
Форма -- это кортеж целых, количество которых совпадает с размерностью.

``` {figure} ./excalidraw/2d-array.excalidraw.png
```

При обращении к элементу сначала указывают номер строки, а затем номер столбца.
Номер столбца не что иное как номер элемента в строке.
```
массив[№ строки][№ столбца]
```

``` {figure} ./excalidraw/3d-array.excalidraw.png
```

При обращении к элементу трехмерного массива сначала указывают номер слоя, затем строки и столбца:
```
массив[№ слоя][№ строки][№ столбца]
```

Из порядка индексов обратим внимание на то, что сначала указывают индекс более крупного контейнера.

## Массив `ndarray`

В основе NumPy лежит класс многомерного массива однородных данных `ndarray`.

Массив `ndarray` обладает тремя характерными атрибутами:
* `ndim` -- размерность массива или количество осей;
* `shape` -- форма, размер массива по каждому из направлений;
* `dtype` -- тип хранящегося элемента.

* Индексация массива начинается с нуля.
* После создания размер массива нельзя изменить.
* Массив -- изменяемый объект.
* Срез создает не копию массива, а его представление; поэтому через срез можно изменить элементы исходного массива.

Размерность заменяется термином **ось**.



## Создание массивов

Функции numpy, создающие массивы `ndarray` называют **конструкторами массива**.
Существуют следующие функции:
* `array`;
* `zeros`, `ones`, `full`, `empty`;
* `{zeros,ones,empty,full}_like`;
* `arange`, `linspace`;
* `identity`, `eye`;
<!--
* `ndarray.astype`;
* генерация случайных чисел;
-->

``` python
arr = np.array([1,2,3])
arr = np.array([[1,2,3],[4,5,6]])
arr = np.array([1,2,3], dtype = np.float64)
```

``` python
arr = np.zeros((2, 3))            # все нули, float64 по умолчанию
arr = np.ones((2, 3), dtype=int)  # все единицы, целые
arr = np.full((2, 3), 7)          # заполнить константой 7
arr = np.empty((2, 3))            # БЕЗ инициализации — мусор в памяти
```

``` python
np.zeros_like(arr)
np.ones_like(arr)
np.full_like(arr, 5)
```

``` python
print(np.arange(0, 10, 2))        # шаг 2, до 10 не включая
print(np.arange(0, 1, 0.25))      # дробный шаг
print(np.linspace(0, 1, 5))       # 5 точек от 0 до 1 включительно
```

``` python
print(np.eye(3))                         # единичная 3x3
print(np.diag([10, 20, 30]))             # диагональная из вектора

# fromfunction: значение = f(индексы). Здесь — таблица сложения
print(np.fromfunction(lambda i, j: i + j, (3, 3), dtype=int))
```
