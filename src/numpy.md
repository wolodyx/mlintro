# Основы NumPy

<!-- Краткое описание NumPy -->
NumPy -- это популярная библиотека Python с открытым исходным кодом для научных вычислений.
В ее основе лежит класс многомерного массива с однородными данными и множество операций вокруг него.

Массивы NumPy как строительные блоки используются во многих популярных библиотеках машинного обучения.
На них основаны или их принимают как входные данные такие библиотеки как Pandas, Scikit-learn, SciPy, Matplotlib, Seaborn, TensorFlow, PyTorch, Keras.
Именно поэтому важно понимать основы и уметь пользоваться NumPy.
Понимание принципов, заложенных в NumPy, не пропадут зря, и помогут при освоении Pandas.

## Эффективность операций NumPy

Сравним скорость выполнения операций над одним миллионом целых чисел в классическом списке Python и одномерном массиве NumPy следующей программой.
Выберем операцию вида `x * 2 + 1`, а для измерения времени воспользуемся магической командой `%timeit`.

```` {note}
Общепринято импортировать модуль NumPy с псевдонимом:
``` python
import numpy as np
```
````

```{code-cell} python
import numpy as np

N = 1_000_000

py_list = list(range(N))
np_array = np.arange(N)

print(f"Сравнение на {N:,} элементах\n")

print("Python list:  [x * 2 + 1 for x in lst]")
%timeit [x * 2 + 1 for x in py_list]

print("\nNumPy array:  arr * 2 + 1")
%timeit np_array * 2 + 1
```

Запуск программы дал следующий вывод.
По нему мы можем судить, что скорость операции NumPy относительно Python-инструкции выше в 64 раза.

```
Сравнение на 1,000,000 элементах

Python list:  [x * 2 + 1 for x in lst]
51.2 ms ± 178 μs per loop (mean ± std. dev. of 7 runs, 10 loops each)

NumPy array:  arr * 2 + 1
803 μs ± 15.1 μs per loop (mean ± std. dev. of 7 runs, 1,000 loops each)
```

Такая значительная разница в скорости стало возможным за счет того, что NumPy известен тип данных элементов и значения в памяти расположены рядом.
Это позволяет применить операцию ко всем данным сразу.
Такие операции называются **векторизированными**.
Конечно, циклы и индексации никуда не делись, они скрыты на уровне реализации библиотеки на языке программирования Си.
Но с точки зрения интерпретатора Python, все элементы массива модифицируются за одну операцию.

Векторизация, скрывая циклы, делает код более читаемым.
Обратите внимание на лаконичность записи выражения операции в векторизированной форме:
```
np_array * 2 + 1
```
Здесь сложнее допустить ошибку, чем если бы применяли операцию к каждому элементу массива.

``` {note}
NumPy предлагает быстрые операции, лаконичные и выразительные формы их записи.
```


## Многомерные массивы

Современные компьютеры оперируют с числами.
В таких областях как численное моделирование и машинное обучение оперируют огромным количеством чисел.
Самый эффективный способ организовать числа для быстрого доступа к ним -- поместить их в массивы.
Разделить числа на группы для их структурирования можно добавив в массив дополнительные измерения.
Двумерные, трехмерные и многомерные массивы являются обычным делом в сложных и объемных вычислениях.
Массивы характеризуются следующими свойствами:
* элементы массива располагаются плотно и фиксированным шагом;
* размер массива заранее известен и неизменяем (изменяемы только содержимое элементов);

Наиболее часто используются одномерные и двумерные массивы.

Каждое из измерений несет смысл.

Рассмотрим примеры, где моделируемые объекты раскладываются на массивы чисел.

<!-- Численное моделирование на структурированной сетке -->

### Набор изображений в формате RGB
Изображения представляются двумерным массивом пикселей.
Каждый пиксель в формате RGB кодируется тремя цветовыми компонентами, обозначаемых через `R` (red, красный), `G` (gree, зеленый) и `B` (blue, синий).
Цветной пиксель вводит дополнительное измерение размером в три в исходный двумерный массив и в итоге группирует набор чисел в трехмерный массив.
``` {figure} ./excalidraw/image-with-rgb.excalidraw.png
```

<!-- Обучение нейросети на изображениях -->
Для обучения нейросети используют *обучающий набор данных*, в нашем случае изображений.
Обучение происходит итерационно, не на всех данных сразу, а на порциях изображений.
Исходный набор данных разбивается на такие порции, называемых *батчами*.
Такая организация вводит в представление выше дополнительные, четвертое и пятое измерения.
В пятом измерении весь датасет разбивается на порции, в четвертом измерении представлены изображения в порции.
``` {figure} ./excalidraw/dataset-batch-img.excalidraw.png
```

Таким образом массив индексация `dataset[i,j,k,l,m]` обращается в наборе данных к `i`-тому батчу, `j`-тому изображению, пикселю в строке `k` и столбце `l` и цветовому каналу под номером `m`.

### Структурированная расчетная сетка

Некоторые численные расчеты в объеме проводят в кубической области, разбитой структурированно на шестигранные ячейки.
В таком разбиении появляется расчетная область, состоящая из узлов, размещенных по трем направлениям, которые обозначают как `I`, `J`, `K`.
Каждый узел в свою очередь представлен точкой из трех координат `x`, `y` и `z`.
В результате мы получаем 4-мерный массив: трехмерный кубический массив, элементами которого являются три числа `(x,y,z)` - еще одно измерение размером 3.
Такой 4-мерный массив описывает геометрию и разбиение расчетной области на ячейки.
Для результатов расчета необходимо будет сохранить вычисленные неизвестные с привязкой к узлам, например: скорости по трем направлениям, давление и температура.
Они встанут на места координат узлов.
Но для нестационарных расчетов, где неизвестные будут меняться, появится дополнительное размерность в виде времени.
В итоге получится 5-мерный массив: по выражению `result[time,i,j,k,y]` мы обращаемся в моменте времени `time` узла индексом `(i,j,k)` и вычисленной величине `y`.



## Связь представления индекса с массивом

<!-- Визуализация многомерности -->
Рассмотрим два приема, позволяющие мысленно изобразить многомерные массивы.
Рассмотрим элеменент массива как прямоугольный контейнер, содержащий некоторое значение, например, число.
Одномерный массив представляет объединение прямоугольников в строку.
Двумерный массив есть одномерный массив одномерных массивов: каждая ячейка такого массива содержит уже не число, а массив строку.
Рекурсивно применяя этот прием для, получаем, что `N`-мерный массив есть массив `(N-1)`-мерного массива.
``` {figure} ./excalidraw/nd-array.excalidraw.png
```

Во втором способе мы используем возможности трехмерного пространства, чтобы нарисовать двумерный массив как таблицу, а трехмерный -- как блок (прямоугольный параллелепипед).
При переходе на четвертое измерение мы снова изображаем массив как строку со вложенными блоками.
В общем случае получается, что N-мерный массив изображается как:
* строка, если N при делении нацело дает в остатке 1;
* таблицу, если дает в остатке 2;
* блок, если N делится нацело.

Содержимое массива будет числом, если `N < 4`, иначе блоком.

<!-- Массивы в памяти -->
Память компьютера представляет последовательность ячеек.
Каким образом многомерная структура данных раскладывается на нее?
Количество измерений массива называется **размерностью**.
Количество ячеек по каждому измерению определяет **форму массива**.
Форма -- это кортеж целых, количество которых совпадает с размерностью.

``` {figure} ./excalidraw/2d-array.excalidraw.png
```

При обращении к элементу сначала указывают номер строки, а затем номер столбца.
Номер столбца не что иное как номер элемента в строке.
```
массив[№ строки][№ столбца]
```

``` {figure} ./excalidraw/3d-array.excalidraw.png
```

При обращении к элементу трехмерного массива сначала указывают номер слоя, затем строки и столбца:
```
массив[№ слоя][№ строки][№ столбца]
```

Из порядка индексов обратим внимание на то, что сначала указывают индекс более крупного контейнера.

## Массив `ndarray`

В основе NumPy лежит класс многомерного массива однородных данных `ndarray`.

Массив `ndarray` обладает тремя характерными атрибутами:
* `ndim` -- размерность массива или количество осей;
* `shape` -- форма, размер массива по каждому из направлений;
* `dtype` -- тип хранящегося элемента.

* Индексация массива начинается с нуля.
* После создания размер массива нельзя изменить.
* Массив -- изменяемый объект.
* Срез создает не копию массива, а его представление; поэтому через срез можно изменить элементы исходного массива.

Размерность заменяется термином **ось**.

```{figure} ./excalidraw/transpose-shape.excalidraw.png
```

## Примеры задач

(repeat-arange)=
### Массив с 10 сгруппированными числами

Иногда нужен массив, в котором одинаковые значения идут подряд, образуя группы.
Такой массив удобно использовать для проверки алгоритмов перемешивания и сортировки.

Создадим массив из 10 чисел, каждое из которых повторяется 7000 раз.
Начнем с последовательности `0, 1, ..., 9`, которую возвращает [`numpy.arange`](https://numpy.org/doc/stable/reference/generated/numpy.arange.html), и повторим каждый ее элемент функцией [`numpy.repeat`](https://numpy.org/doc/stable/reference/generated/numpy.repeat.html):

``` {code-cell} python
y = np.repeat(np.arange(10), 7000)
print(y.shape)
print(y[:5], y[6995:7005], y[-5:])
```

Функция `np.repeat(a, repeats)` принимает массив `a` и число повторений.
Если `repeats` -- скаляр, то каждый элемент повторяется указанное число раз.
Длина результата равна `len(a) * repeats`, то есть `10 * 7000 = 70000`.
Поэтому `y.shape` возвращает `(70000,)` -- это одномерный массив.

Выведенные срезы показывают структуру массива:
* `y[:5]` -- первые пять элементов, все они равны `0`;
* `y[6995:7005]` -- срез пересекает границу групп: пять нулей и пять единиц;
* `y[-5:]` -- последние пять элементов, все они равны `9`.


(shuffle)=
### Перемешиваем массив

Отсортированные и сгруппированные данные часто влияют на результат не в лучшую сторону, поэтому требуют обратной процедуры -- перемешивания.
В предыдущем разделе массив `y` был отсортирован.
Давайте перемешаем его.

Метод [`np.random.Generator.permutation`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.permutation.html) возвращает перемешанную копию массива и сохраняет исходный массив:
```{code-cell} python
rng = np.random.default_rng(0)
shuffled = np.random.permutation(y)
print(shuffled[:20])
print(shuffled.shape)
```

В начале `shuffled` теперь стоят случайные числа от `0` до `9`, а не нули, но форма массива сохранилась.
Перемешивание меняет только порядок, а состав значений остается прежним.
Убедимся, что после сортировки перемешанного массива получается исходный `y`:

```{code-cell} python
print(np.array_equal(np.sort(shuffled), y))
```

Метод [`numpy.random.Generator.shuffle`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.shuffle.html) перемешивает данные внутри исходного массив.

Для многомерного массива `np.random.permutation` переставляет строки, то есть перемешивает элементы вдоль первой оси и сохраняет целостность строк.
Если передать функции целое число `n`, она вернет случайную перестановку чисел `0, 1, ..., n-1`.
Этот прием используют, чтобы согласованно перемешать несколько массивов.
Если нужно перемешать признаки `X` и метки `y`, нельзя перемешивать их независимо, иначе нарушится соответствие между строками.
Сначала получают перестановку индексов, а затем применяют ее к обоим массивам:
```python
rng = np.random.default_rng(0)
idx = rng.permutation(len(X))
X_shuffled, y_shuffled = X[idx], y[idx]
```

Иногда нужно перемешать только часть массива, оставив остальную без изменений.
Для этого неизменяемую часть соединяют с перемешанной частью.
Объект [`numpy.r_`](https://numpy.org/doc/stable/reference/generated/numpy.r_.html) позволяет записать конкатенацию массивов в виде `np.r_[a, b]`:

```{code-cell} python
rng = np.random.default_rng(0)

partial = np.r_[y[:5000], rng.permutation(y[5000:])]

print(partial[:10])
print(partial[4990:5010])
print(partial.shape)
```

Здесь `y[:5000]` -- первые 5000 элементов, которые остаются на своих местах.
В сгруппированном массиве это 5000 нулей.
Выражение `rng.permutation(y[5000:])` перемешивает оставшиеся 65000 элементов, а `np.r_` присоединяет результат к неизменяемому началу.
Поэтому первые 5000 элементов `partial` по-прежнему равны нулю, а после них идут значения из перемешанного "хвоста": 2000 оставшихся нулей и по 7000 чисел от 1 до 9.
В результате массив уже не является отсортированным.

`np.r_` для одномерных массивов делает то же, что [`numpy.concatenate`](https://numpy.org/doc/stable/reference/generated/numpy.concatenate.html), но позволяет короче записать соединение.
Важно, что создается новый массив, а `y` не изменяется.


### Отсортирован ли массив?

Проверка упорядоченности -- типовая операция при обработке данных.
Например, перед двоичным поиском нужно убедиться, что массив отсортирован, а при анализе временного ряда -- что наблюдения идут по возрастанию времени.
В NumPy нет отдельной функции `is_sorted`, поэтому проверку выражают через уже известные операции над массивами.

Массив отсортирован по возрастанию, если каждый следующий элемент не меньше предыдущего.
Сравним два среза массива: `arr[:-1]` содержит все элементы, кроме последнего, а `arr[1:]` -- все, кроме первого.
Операция `<=` применяется к ним поэлементно и возвращает булев массив.
Функция [`numpy.all`](https://numpy.org/doc/stable/reference/generated/numpy.all.html) вернет `True`, только если все сравнения истинны:

```{code-cell} python
import numpy as np

arr = np.array([1, 2, 2, 5, 8])
print(arr[:-1] <= arr[1:])
print(np.all(arr[:-1] <= arr[1:]))
```

Для проверки сортировки по убыванию знак сравнения меняется на противоположный:

```{code-cell} python
print(np.all(arr[:-1] >= arr[1:]))
```

Срезы не копируют данные, а создают представления, поэтому такая проверка выполняется за один проход по массиву, то есть имеет сложность $O(n)$.
Массив из нуля или одного элемента считается отсортированным: сравнение дает пустой булев массив, а `np.all` для пустого массива возвращает `True`.

Оформим проверку в виде функции.
Для пустого массива и массива из одного элемента сразу возвращаем `True`, а для остальных сравниваем соседние элементы:

```{code-cell} python
def is_sorted(arr, ascending=True):
    if arr.ndim != 1:
        raise ValueError("ожидается одномерный массив")
    if arr.size < 2:
        return True
    if ascending:
        return bool(np.all(arr[:-1] <= arr[1:]))
    return bool(np.all(arr[:-1] >= arr[1:]))


for values in ([1, 2, 2, 5], [9, 7, 3], [1, 3, 2], [], [42]):
    arr = np.array(values)
    print(f"{str(values):15} возрастание={is_sorted(arr)}  убывание={is_sorted(arr, ascending=False)}")
```

```{code-cell} python
arr = np.array([1, 2, 2, 5])
print("неубывающий:", np.all(arr[:-1] <= arr[1:]))
print("строго возрастающий:", np.all(arr[:-1] < arr[1:]))
```

```` {warning}
Следует помнить о пропусках.
Любое сравнение с `NaN` дает `False`, поэтому массив, содержащий `NaN`, будет признан неотсортированным.
Если пропуски нужно игнорировать, их удаляют перед проверкой:

```{code-cell} python
arr = np.array([1.0, np.nan, 3.0])
print("с NaN:", np.all(arr[:-1] <= arr[1:]))

clean = arr[~np.isnan(arr)]
print("без NaN:", np.all(clean[:-1] <= clean[1:]))
````

### Зашумляем изображение

В этой задаче мы добавим аддитивный и импульный шумы в изображение из [набора данных MNIST](./datasets.md#mnist).
С помощью шума случайно исказим некоторые значения пикселей изображения.
Зашумленные изображения помогут в дальнейшем проверить устойчивость модели к искажениям, расширить (аугментировать) обучающий набор новыми данными или обучить модель восстанавливать изображение.

Поскольку шум случаен, для его получения воспользуемся [генератором псевдослучайных](https://numpy.org/doc/stable/reference/random/generator.html) чисел из Numpy.
Функция [`numpy.random.default_rng`](https://numpy.org/doc/stable/reference/random/generator.html#numpy.random.default_rng) возвращает объект `Generator`, методы которого и будут генерировать числа.
Аргумент `seed` задает начальное состояние генератора, называемого также **затравкой**.
При одном и том же значении затравки последовательность случайных чисел будет повторяться для каждого запуска сценария, что позволит каждый раз получать один и тот же результат.

``` python
import numpy as np
rng = np.random.default_rng(seed=0)
```

У генератора `rng` есть методы для получения чисел из разных распределений:
* [`normal`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.normal.html) -- нормальное (гауссово) распределение;
* [`uniform`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.uniform.html) -- вещественные числа, равномерно распределенные в заданном интервале;
* [`integers`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.integers.html) -- целые числа, равномерно распределенные в заданном интервале;
* [`random`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.random.html) -- вещественные числа, равномерно распределенные в интервале `[0, 1)`.

``` {note}
В ранних версиях Numpy для генерации псевдослучайных чисел использовали глобальные функции [`numpy.random.normal`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.normal.html), [`np.random.seed`](https://numpy.org/doc/stable/reference/random/generated/numpy.random.seed.html) и другие.
Но для нового кода рекомендуется использовать объектный интерфейс и функцию [`np.random.default_rng`](https://numpy.org/doc/stable/reference/random/generator.html#numpy.random.default_rng).
```

Загрузим набор рукописных цифр MNIST и выберем одно изображение.
Каждое изображение в MNIST хранится как вектор из `28 * 28 = 784` чисел, поэтому его нужно привести к форме `(28, 28)`.
Значения пикселей в исходном изображении лежат в диапазоне от 0 до 255 типа `int64`.
Для добавления шума удобно перевести массив в вещественный тип, иначе дробные значения будут отброшены при записи в целочисленный массив.

```{code-cell} python
from sklearn.datasets import fetch_openml
mnist = fetch_openml('mnist_784', version=1, as_frame=False, parser='liac-arff')
X, y = mnist.data, mnist.target

image_index = 0
image = X[image_index].reshape(28, 28).astype(np.float64)

print(f"Форма изображения: {image.shape}")
print(f"Диапазон значений: {image.min()}..{image.max()}")
print(f"Метка класса: {y[image_index]}")
```

Отобразим изображение средствами Matplotlib.
Разбор кода визуализации показан [здесь](./matplotlib.md#draw-image).
```{code-cell} python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.imshow(image, cmap='gray_r')
ax.set_title(f"Исходная цифра {y[0]}")
ax.axis('off')
plt.show()
```

При аддитивном (или гауссовом) шуме яркость каждого пикселя отклоняется от истинной случайным образом (на величину $\varepsilon$) по закону нормального распределения с нулевым средним и стандартным отклонением $\sigma$.
Параметр $\sigma$ управляет силой шума: чем он больше, тем сильнее искажается изображение.
После сложения значения могут выйти за пределы допустимого диапазона, поэтому их ограничивают функцией [`numpy.clip`]().
$$
I_{\text{noisy}} = \operatorname{clip}(I + \varepsilon,\ 0,\ 255),
\qquad
\varepsilon \sim \mathcal{N}(0, \sigma^2).
$$

```{code-cell} python
def add_gaussian_noise(image, sigma, rng):
    noise = rng.normal(loc=0.0, scale=sigma, size=image.shape)
    noisy = np.clip(image + noise, 0, 255)
    return noisy.astype(np.uint8)
```

Сравним исходное изображение с зашумленными при разных значениях $\sigma$.
Для каждого уровня шума создаем отдельный генератор с одной и той же затравкой, чтобы результаты можно было воспроизвести.
```{code-cell} python
sigmas = [10, 30, 60]
fig, axes = plt.subplots(ncols=len(sigmas)+1)

axes[0].imshow(image, cmap='gray_r')
axes[0].set_title("Исходное")

for ax, sigma in zip(axes[1:], sigmas):
    rng = np.random.default_rng(seed=0)
    noisy = add_gaussian_noise(image, sigma, rng)
    ax.imshow(noisy, cmap='gray_r')
    ax.set_title(f"σ = {sigma}")

for ax in axes:
    ax.axis('off')

plt.tight_layout()
plt.show()
```

При импульсном шуме случайные пиксели внезапно меняют свою яркость или цвет, превращаясь в хаотично разбросанные по кадру белые или черные точки.
Следующий код ниже заменяет отдельные пиксели на черные (0) или белые (255).
Доля измененных пикселей задается параметром `amount`.
Для выбора пикселей используем матрицу равномерно распределенных случайных чисел из интервала `[0, 1)`, генерируемого методом [`random`]().
Пиксели со значением меньше `amount/2` делаем черными, а больше `1-amount/2` -- белыми.
```{code-cell} python
def add_impulse_noise(image, amount, rng):
    noisy = image.copy()
    mask = rng.random(image.shape)
    noisy[mask < amount / 2] = 0
    noisy[mask > 1 - amount / 2] = 255
    return noisy.astype(np.uint8)
```

Воспользуемся созданной функцией выше и зашумим исходное изображение тремя разными значениями `amount`:
```{code-cell} python
amounts = [0.01, 0.05, 0.15]
fig, axes = plt.subplots(ncols=len(amounts)+1)

axes[0].imshow(image, cmap='gray_r', vmin=0, vmax=255)
axes[0].set_title("Исходное")

for ax, amount in zip(axes[1:], amounts):
    rng = np.random.default_rng(seed=0)
    noisy = add_impulse_noise(image, amount, rng)
    ax.imshow(noisy, cmap='gray_r', vmin=0, vmax=255)
    ax.set_title(f"amount = {amount}")

for ax in axes:
    ax.axis('off')

plt.tight_layout()
plt.show()
```
