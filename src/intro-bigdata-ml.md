# Введение в анализ данных

## Цель

Сформировать общее представление о задачах анализа данных и машинного
обучения, познакомиться с ключевыми понятиями (Big Data, предиктивная
аналитика) и инструментами (Python и его библиотеки, Jupyter Notebook).

## Большие данные

<!-- Данные vs. Информация -->
**Данные** -- это "сырые" факты, сигналы, символы или записи, которые сами по себе не имеют смысла без обработки и контекста.
**Информация** -- это данные, которые были обработаны, упорядочены и получили контекст, благодаря чему их можно понять и использовать для решений.

Примеры:
* Данные: состояние атмосферы вчера и сейчас на территории страные; информация: какая погода будет завтра.
* Данные: какая книга и когда продана издательством; информация: книги бестселлеры.
* Данные: какая продукция и когда была продана заводом; информация: какую продукцию производить.
* Данные: массив новостных сообщений; информация: какую из акций продать, а какую купить.

<!-- Структурированные данные -->
**Структурированные данные** – это данные, имеющие стандартизированный формат, что обеспечивает эффективный доступ для ПО и людей.
Обычно они представлены в форме таблицы со строками и столбцами, четко определяющими атрибуты данных.
Компьютеры могут эффективно обрабатывать структурированные данные для получения аналитики благодаря их количественному характеру. 

Примеры структурированных данных:
* каталог продуктов;
* телефонный справочник;
* прайс-лист;
* ...

Такие данные удобно хранить в **реляционных базах данных** в виде таблиц и связей между ними и манипулировать данными через язык реляционных запросов SQL.
Описание структуры, содержания и ограничений над данными в **схеме базы данных**.

<!-- Преимущества и недостатки структурированных данных -->
Преимущества структурированных данных:
* простота обработки;
* стандартные инструменты;
* высокая точность и согласованность;
* эффективность;
* надежность транзакций.

Недостатки структурированных данных:
* требует предварительного проектирования схемы;
* жесткая схема (сложно мигрировать);
* не подходит для разнородных данных;
* ограниченная масштабируемость;

<!-- Неструктурированные данные -->
Неструктурированные данные -- это те данные, у которых нет заранее заданной схемы, модели или формата.

Примеры неструктурированных данных:
* текстовые: письма, документы, посты в соцсетях, чаты;
* графические: изображение, видео;
* голосовые;
* машинный вывод: логи, телеметрия.

Преимущества неструктурированных данных:
* гибкость: можно хранить что угодно;
* богатство информации;

Недостатки:
* сложно обрабатывать;

<!-- Полуструктурированные данные -->
Выделим промежуточную форму как полуструктурированные данные.
**Полуструктурированные данные** -- это данные, которые не имеют жёсткой табличной схемы, но при этом содержат внутреннюю структуру: теги, ключи, атрибуты, иерархию.
Их называют "самоописывающими", так как структура хранится внутри самих данных. <!-- Гибкая схема -->

Примеры:
* JSON, XML, YAML;
* HTML;
* электронное письмо, где выделены заголовок и тело;

<!-- Что такое Big Data -->
Под термином **Big Data** обозначают структурированные и неструктурированные данные больших объёмов и значительного многообразия, эффективно обрабатываемых горизонтально масштабируемыми программными инструментами.
Обычно описываются набором характеристик "V":
* Volume, объём данных;
* Velocity, скорость поступления/обновления;
* Variety, разнообразие форматов (таблицы, текст, изображения, логи);
* Veracity, достоверность и качество данных;
* Value, ценность, извлекаемая из данных.

Большие объемы данных генерируют:
* веб-сервера в виде логов;
* банковская система;
* социальные сети;
* телеметрия.

## Машинное обучение

**Машинное обучение** -- область, в которой система обучается на данных и выдаёт предсказания или принимает решения без явного программирования правил.

Основные типы обучения:
* С учителем (supervised), модель учится на размеченных данных (есть целевой признак); (классификация, регрессия).
* Без учителя (unsupervised), разметки нет, ищутся скрытые структуры ; (кластеризация, поиск аномалий).
* С подкреплением (reinforcement), агент обучается через вознаграждение; (управление, игры).

## Работа с данными

Типовой жизненный цикл проекта анализа данных:

1. **Сбор** данных из источников (файлы, БД, API, логи).
2. **Предобработка** -- очистка от пропусков, дубликатов, аномалий, приведение типов.
3. **Исследовательский анализ (EDA)** -- визуализация, поиск закономерностей.
4. **Построение модели** -- выбор алгоритма, обучение, оценка качества.
5. **Внедрение** -- использование модели в продукте/сервисе.

## Предиктивная аналитика

**Предиктивная аналитика** -- создание моделей, предсказывающих будущие события или значения на основе исторических данных.

Виды аналитики по глубине:

- **описательная** -- "что произошло?" (отчёты, статистика);
- **диагностическая** -- "почему произошло?" (корреляции, факторы);
- **предиктивная** -- "что произойдёт?" (модели машинного обучения);
- **предписывающая** -- "что делать?" (оптимизация решений).

Примеры предиктивных задач в цифровых сервисах: прогноз спроса, отток
клиентов (churn), рекомендации, скоринг, детекция мошенничества.

## Инструменты для работы

Основным языком программирования в анализе данных и машинном обучении стал **Python**.
Он одновременно прост в использовании и включает широкий функционал для обработки и анализа данных.
Сюда входят следующие библиотеки:
* **Pandas** для обработки табличных данных;
* **NumPy** включает многомерные массивы, функции из линейной алгебры и численные методы;
* **SciPy** содержит алгоритмы для научных вычислений, статистики и оптимизации;
* **Matplotlib** строит графики;
* **Scikit-learn** включает алгоритмы машинного обучения;
* **Keras** предлагает высокоуровневый интерфейс для работы с нейронными сетями поверх TensorFlow;
* **Jupyter Notebook** предоставляет интерактивную среду разработки и документирования.

Стек условно делится на уровни:

* *работа с данными*: NumPy, Pandas, SciPy;
* *визуализация*: Matplotlib;
* *доступ к моделям*: классические алгоритмы Scikit-learn и нейронные сети Keras.

## Среда разработки Jupyter Notebook

**Jupyter Notebook** -- интерактивная веб-среда, где код, результат выполнения, текст и графики живут в одном документе.

Преимущества:

- **интерактивность** -- выполнение ячеек по отдельности, немедленный вывод;
- **наглядность** -- графики и таблицы встраиваются рядом с кодом;
- **документирование** -- Markdown-разметка для пояснений и формул;
- **воспроизводимость** -- ноутбук как единый артефакт анализа.

Основные элементы интерфейса:

- **ячейки кода** (`code`) -- исполняемый Python-код;
- **ячейки разметки** (`markdown`) -- пояснения, заголовки, формулы;
- **kernel** -- процесс Python, хранящий состояние переменных между ячейками.

```python
# пример ячейки кода в Jupyter
import pandas as pd

df = pd.DataFrame({"a": [1, 2, 3], "b": [4, 5, 6]})
df.head()
```

Запуск: `jupyter notebook` (классический интерфейс) или
`jupyter lab` (современный интерфейс).
