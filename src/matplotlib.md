# Основы Matplotlib

Процесс исследования данных связан с визуализацией.
Существует много инструментов визуализации данных, но Matplotlib -- это самый популярный из них.


Общепринято импортировать Matplotlib с псевдонимом:
``` python
import matplotlib as plt
```


## Терминология

Рисунок `Figure`, график/подграфик
